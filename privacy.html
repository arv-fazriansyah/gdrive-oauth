Privacy Policy

Last updated: 18 November 2026

This policy describes how the private OAuth client for the project “Personal Google Drive Backup (rclone)” (“the client”) handles Google user data. The client is operated by one individual for his own personal use on his own computer.

1. What Google user data is accessed

When the owner authorises the client, Google grants these scopes:

  • https://www.googleapis.com/auth/drive — create, read, update and delete files in the owner's Drive.
  • https://www.googleapis.com/auth/docs — create and edit Google Docs format files (used only if a backup file is ever converted).
  • https://www.googleapis.com/auth/drive.metadata.readonly — read file names and metadata while listing existing backups.

In practice the client touches only the folder the owner selects and the backup files inside it.

2. How the data is used

  • To upload the owner's configuration files as a backup.
  • To list files in that folder so older backups can be removed.
  • To download a file again if the owner restores a backup.

No other use is made of the data. The data is not used for advertising, profiling, or training models.

3. Storage, sharing and disclosure

  • Backups remain in the owner's own Google Drive account. No copy is stored anywhere else by this project.
  • OAuth tokens and client credentials are stored locally on the owner's computer, in the rclone configuration file.
  • No data is sold, rented, or shared with third parties. There are no analytics, trackers, or advertising services.
  • Data may be disclosed only if required by applicable law.

4. Retention and deletion

The client keeps the most recent backup and deletes older ones automatically. The owner can delete any backup file directly in Google Drive, and can revoke the client's access at any time at myaccount.google.com/permissions, which invalidates the stored tokens.

5. Limited Use disclosure

The client's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Security

Communication with Google uses HTTPS. Credentials are kept on the owner's computer and are never transmitted to any service other than Google's own API endpoints.

7. Changes

If this policy changes, the updated version will be published on this page with a new “last updated” date.
