Google Drive Backup

Kebijakan Privasi

Terakhir diperbarui: 19 November 2026

Kebijakan ini menjelaskan bagaimana klien OAuth 2.0 “Google Drive Backup” (“klien OAuth”) menangani data pengguna Google. Klien OAuth ini dapat dipakai oleh aplikasi klien apa pun dan tidak terikat pada satu aplikasi tertentu. Setiap pengguna hanya mengakses akun Google miliknya sendiri.

1. Data pengguna Google yang diakses

Saat pengguna memberi otorisasi, Google memberikan cakupan (scope) berikut:

  • https://www.googleapis.com/auth/drive — membuat, membaca, memperbarui, dan menghapus file di Drive pengguna.
  • https://www.googleapis.com/auth/docs — membuat dan menyunting file berformat Google Docs (hanya dipakai jika sebuah file cadangan sewaktu-waktu dikonversi).
  • https://www.googleapis.com/auth/drive.metadata.readonly — membaca nama file dan metadata saat menampilkan daftar cadangan yang sudah ada.

Dalam praktiknya aplikasi klien hanya menyentuh folder yang dipilih pengguna dan file cadangan di dalamnya.

2. Cara data digunakan

  • Mengunggah file yang dipilih pengguna atau aplikasi klien sebagai cadangan.
  • Menampilkan daftar file di folder tersebut agar cadangan lama dapat dihapus.
  • Mengunduh file kembali jika pengguna memulihkan cadangan.

Tidak ada penggunaan lain atas data. Data tidak dipakai untuk iklan, pembuatan profil, maupun pelatihan model.

3. Penyimpanan, pembagian, dan pengungkapan

  • Cadangan tetap berada di akun Google Drive milik pengguna. Proyek ini tidak menyimpan salinannya di tempat lain.
  • Token OAuth dan kredensial klien disimpan secara lokal di perangkat pengguna oleh aplikasi klien yang dipakai.
  • Pengembang tidak memiliki akses ke file cadangan, isi Drive, maupun token pengguna.
  • Data tidak dijual, disewakan, atau dibagikan kepada pihak ketiga. Tidak ada analytics, pelacak, atau layanan iklan.
  • Data hanya dapat diungkapkan jika diwajibkan oleh hukum yang berlaku.

4. Retensi dan penghapusan

Aplikasi klien menyimpan cadangan terbaru dan menghapus cadangan yang lebih lama secara otomatis. Pengguna dapat menghapus file cadangan kapan saja langsung di Google Drive, dan dapat mencabut akses klien OAuth kapan saja di myaccount.google.com/permissions, yang membuat token yang tersimpan tidak berlaku lagi.

Karena seluruh data berada di akun Google dan perangkat pengguna, tidak ada data yang perlu dihapus dari sisi pengembang.

5. Pengungkapan Limited Use

Penggunaan informasi yang diterima dari Google API oleh aplikasi ini tunduk pada Google API Services User Data Policy, termasuk persyaratan Limited Use.

6. Keamanan

Komunikasi dengan Google menggunakan HTTPS. Kredensial disimpan di perangkat pengguna dan tidak pernah dikirim ke layanan lain selain endpoint API milik Google.

7. Perubahan

Jika kebijakan ini berubah, versi terbaru akan diterbitkan di halaman ini dengan tanggal “terakhir diperbarui” yang baru.
