Personal Google Drive Backup (rclone)

This page is the application home page for a private OAuth client used by a single person, the project owner, to back up files from his own computer to his own Google Drive using rclone, an open-source command line tool.

What the application does

  • Runs locally on the owner's Windows computer. There is no server, no web dashboard and no user accounts.
  • Uploads a small set of configuration files (editor settings, agent instructions, one JSON backup) to a single folder in the owner's own Google Drive.
  • Lists and removes old backup files in that same folder, so that only the newest backup is kept.

Who uses it

One person only — the owner of the Google account that grants access. The client is not distributed, not published to any app store, and has no other users. Access is granted through Google's OAuth consent screen and can be revoked at any time at myaccount.google.com/permissions.

Data and privacy

The client reads and writes only the files it created in the folder the owner chooses. It does not read, collect, or transmit the owner's other Drive content, and it sends nothing to third parties. Full details are in the Privacy Policy.
