Google Drive Backup

Klien OAuth 2.0 untuk mencadangkan file dari aplikasi klien mana pun ke Google Drive milik pengguna sendiri. Tidak terikat pada satu aplikasi atau satu alat tertentu.

Berjalan lokal · Tanpa server · Tanpa akun tambahan

Apa yang dilakukan aplikasi

  • Berjalan lokal di perangkat pengguna melalui aplikasi klien yang dipakai. Tidak ada server aplikasi, dasbor web, atau sistem akun tambahan.
  • Memberi otorisasi OAuth 2.0 agar aplikasi klien dapat mengunggah file ke satu folder khusus di Google Drive pengguna.
  • Memungkinkan aplikasi klien menampilkan daftar, mengunduh, dan menghapus file cadangan lama di folder tersebut, sehingga hanya cadangan terbaru yang disimpan.

Siapa yang dapat menggunakannya

Siapa saja yang memiliki akun Google dapat memberi otorisasi kepada aplikasi klien pilihannya untuk mencadangkan file ke akun Google Drive miliknya sendiri. Klien OAuth ini tidak terikat pada satu aplikasi tertentu, sehingga dapat dipakai oleh aplikasi desktop, alat baris perintah, maupun layanan lain yang mendukung OAuth 2.0.

Setiap pengguna memberi otorisasi pada akun Google miliknya melalui layar persetujuan OAuth, dan dapat mencabut akses kapan saja di myaccount.google.com/permissions. Tidak ada pendaftaran, langganan, atau akun tambahan.

Data dan privasi

Aplikasi klien hanya membaca dan menulis file yang dibuatnya di folder yang dipilih pengguna. Aplikasi tidak membaca, mengumpulkan, atau mengirimkan konten Drive lain milik pengguna, dan tidak mengirim data apa pun ke pihak ketiga. Karena berjalan sepenuhnya di perangkat pengguna, pengembang tidak memiliki akses ke file cadangan maupun token pengguna. Rincian lengkap, termasuk cakupan Google API yang dipakai dan cara menghapus data, ada di Kebijakan Privasi.

Penggunaan informasi yang diterima dari Google API oleh aplikasi ini tunduk pada Google API Services User Data Policy, termasuk persyaratan Limited Use.
