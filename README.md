# gdrive-oauth

Landing page and privacy policy for a private OAuth client used by a single self-hosted
[rclone](https://rclone.org/) instance to back up configuration files to the owner's own Google Drive.

Published with GitHub Pages:

- `index.html` — application home page
- `privacy.html` — privacy policy

These URLs are supplied to Google Cloud Console (OAuth consent screen → Branding) so the
personal-use app can be published out of "Testing" mode.
